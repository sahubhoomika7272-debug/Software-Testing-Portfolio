# E-Commerce Website Manual Testing Project

## 📋 Project Overview
Comprehensive manual testing project for an E-Commerce web application covering all major functional modules.

## 🎯 Testing Scope
- **Login Module**: User authentication, validation, error handling
- **Registration Module**: New user registration, field validation
- **Product Search Module**: Search functionality, filters, sorting
- **Cart Module**: Add/Remove items, quantity management
- **Checkout Module**: Order placement, address management
- **Payment Module**: Payment processing, order confirmation

## 📁 Project Structure
E-Commerce-Manual-Testing/
├── Test-Plans/ # Test strategy and planning documents
├── Test-Cases/ # Detailed test cases for each module
├── Bug-Reports/ # Bug reporting templates and samples
├── Test-Reports/ # Test execution and summary reports
└── Test-Data/ # Test data used across modules
